# Фото на странице программы

Фото подбираются по направлению программы (функция `topic()` в `js/program.js`).
`hero-*.webp` — объект на фоне неба для шапки программы (небо вырезано, 836×556 = 2× от 418×278).
`about-*.jpg` — фото для блока «О программе» (594×444 = 2× от 297×222).

`hero-arch.webp` и `about-arch.jpg` взяты из макета в Figma. Остальные фото с Unsplash
(лицензия Unsplash: можно бесплатно использовать и изменять, указывать автора не обязательно).
